INTEGRATION & WORKFLOW

Step 01

Install Runtime Core

Install the lightweight zero-dependency core from the Quizzman registry:

$ npm i @qmf/runtime@4.0.0-alpha.1
Step 02

Declare Manifest Contract

Create qmf.json to declare module routes, event contracts, and plugin dependencies:

{
  "$schema": "https://ui.quizzman.com/qmf/schemas/v4/contract.json",
  "name": "my-study-app",
  "version": "1.0.0",
  "plugins": ["@qmf/plugin-router", "@qmf/plugin-state"]
}
Step 03

Bootstrap in Browser

Import and bootstrap with pure standard vanilla JavaScript:

import { bootstrap } from 'https://ui.quizzman.com/qmf/v4/runtime.js';

bootstrap({ manifest: './qmf.json' }).then(app => {
  console.log('Quizzman UI Ready', app);
});
