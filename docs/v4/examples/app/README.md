# Example Application — qmf-example-dictionary

Demonstrates QMF 4.0 **vanilla JS** contract, two modules (auth plugin + dictionary), schema-validated events, and inspect.

All sources are `.js` (ESM). No TypeScript.

## Run (when CLI M2 ships)

```bash
cd docs/v4/examples/app
pnpm install
pnpm doctor
pnpm dev
```

## Structure

See `qmf.schema.json` and `src/modules/*`.
