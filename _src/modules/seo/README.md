# QMF SEO / Brand Identity module

CDN:

```
https://ui.quizzman.com/qmf/dist/modules/seo/qmf-seo.js
```

Prefer **SSR** JSON-LD in each site's document shell (`data-qmf-identity="1"`).

This module is the shared generator / client API (`QMF.siteIdentity`) and must not be the only source of structured data after hydration.
