# QMF self-hosted fonts

Canonical URL: `https://ui.quizzman.com/qmf/assets/fonts/`

- `fonts.css` — Inter + Outfit variable (latin, latin-ext, vietnamese)
- `fontawesome/` — Font Awesome 6.4.0 Free (css + woff2)

Do not load `fonts.googleapis.com`, `fonts.gstatic.com`, or `cdnjs.cloudflare.com` for these faces.

Debug console: `?qmf-debug=1` or `localStorage.qmf-debug=1`.
